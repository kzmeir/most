# Поток A — Управление проектами (`modules/pm`)

Основа — регламенты `\\MostServer\Материалы для проектирования\Регламенты\` («Регламент проектирования и разработки для Рабочего проекта.docx», «Дорожная карта проекта\Эскизный проект (ЭП)_06-10-2025.xmind»), реестр `MOST_Планирование_проектов.xlsx` (Google Drive, fileId `1zkp4Lwq7p4y0dpEmPOw33zIrOyEAosMs`: 20 объектов РП, 10 блокеров, 17 задач Trello, шаблон этапов из 79 пунктов) и бюджеты по разделам `G:\Мой диск\Финансы\Бюджеты проектов\MOST_Проекты РП_Бюджет.xlsx`.

## Решения директора
- Стадии: **Концепция** (форэскиз 10 % → концепция 20 % → согласование; ЭП — 70 % отдельным проектом) → **ЭП** → **РП** → **Авторский надзор** (запуск + этап на каждый месяц). Концепцию и ЭП ведёт ПМ (`pmId`), РП и АН — ГИП (`gipId`). Каждая стадия — отдельная карточка, передача создаёт следующую и закрывает текущую.
- ГИП и руководители разделов заходят только в этот модуль, финансов не видят. Субподрядчики в систему не заходят — их пункты (КЖ, ЭЛ, СС, МОПБ, ОВОС…) отмечает руководитель раздела, в пункте поле «Исполнитель-подрядчик» (подсказки — подрядчики финансового проекта из `db.subcontracts`).
- Бюджет и маржу видят руководители и ГИП/ПМ с флагом `seeBudget`. Деньги модуль не вводит: план разделов («Внутренние / Субподряд», как в таблице бюджетов) + факт из финансов по привязанному `projectId`.
- Уведомлений нет: счётчики в меню («Мои задачи» — просроченные мои пункты, «Блокеры» — открытые > 14 дней) и списки.
- В карточке концепции/ЭП — вкладка «Миро» (`miroUrl` → `https://miro.com/app/live-embed/<id>/`).
- Папка проекта на сервере — поле `folder` (стандарт `S:\№-год-название`, разделы 00-ИРД … 13-TH); модуль папки не создаёт, только ссылка «Открыть папку», «Скопировать путь» и подсказка имени.

## Сделано (24.09.2026, ветка erp/pm)

**domain.js** (`window.MostPM`): шаблоны 4 стадий — концепция 13 пунктов, ЭП 35, **РП 79** (сверено с листом «Шаблон этапов» реестра, роли/недели/критерии из регламента; было 68), АН 3 + 5 пунктов на месяц; права (`canOpen/isLeader/isManager/canCreate/canEditItem/canBudget`); план сроков (`plan`: этапы последовательно, пункты параллельно, длительность этапа — самый долгий пункт; `fitTo` — под дату по договору); `summary/dashboard` (просрочено, «горит» ≤ 14 дн., воронки, загрузка ГИП/ПМ), Гант по месяцам (`ganttMonths/ganttLoad`), `budgetCalc`, `blockerAge`, `miroEmbed`, `folderName`, `stageIndex`.

**server.js** (`/api/pm/*`, права проверяются на сервере, финансовых API браузер не зовёт):
`GET overview`, `GET my`, `GET badges`, `GET finance/projects` (руководитель), `GET|POST projects`, `GET|PUT|DELETE projects/:id`, `POST projects/:id/plan` (`{start, fit}`), `POST projects/:id/handover` (концепция → ЭП, ЭП → РП; `{gipId|pmId, start, due, comment}`), `POST projects/:id/items`, `PUT|DELETE items/:id` (поля `done, na, due, note, assigneeId, contractor, doneNote`; менеджер ещё `title, role, weeks, crit, stage`), `GET|POST blockers`, `PUT|DELETE blockers/:id`, `POST import` (руководитель; JSON от импортёра, режимы `skip|replace`). Карточка отдаёт `contractors` (подсказки), `folderHint`, `finance`, `budget`+`fact` (только при `canBudget`), `financeProjects` (руководитель). `createProject(ctx, fields, userId)` — сигнатура прежняя (+ `fields.fit`, `fields.months`, `fields.budget`).

**ui.js** — экраны: Сводка (KPI, статусы, воронки 4 стадий, загрузка ГИП/ПМ, Гант по месяцам с загрузкой студии, кнопки «+ Проект» и «Импорт реестра»), реестры «Эскизные проекты», «Рабочие проекты», «Концепции и АН» (вкладки; фильтры статус / мои / поиск), карточка `#/pmp?id=…&tab=…` (шапка, KPI, вкладки Этапы / Блокеры / Бюджет / Миро / О проекте; чек-лист по этапам с критериями, «сделано», «не требуется», срок, исполнитель, подрядчик, заметка; «Разложить сроки», «Передать в ЭП/РП», «✎ Проект», удаление), «Мои задачи» (группы по объектам, только просроченные), «Блокеры» (все проекты, > 14 дней красным), инструкция модуля (`help`), счётчики через `ui.setBadge` + `onNav`. Таблицы в прокручиваемых контейнерах, карточка в одну колонку на телефоне.

**tools/import_pm.py** — реестр + бюджеты → `data-dev/pm/pm-import.json` (20 объектов: текущий этап → пункты прошлых этапов отмечены «по реестру», задачи Trello — дополнительные пункты этапа, блокеры с `since` = дата реестра, бюджеты 8 объектов, карта привязки к кодам финансовых проектов `FINANCE_MAP`, проверка кодов по db). **tests/api_test.sh** — 80 проверок по ролям.

## Как проверить
```
cd finance-app
set DATA_DIR=data-dev\pm& set DEV_USER=owner& set PORT=3101& node server.js      # http://localhost:3101 → «Проекты»
bash modules/pm/tests/api_test.sh                                                  # 80 ✓: owner, partner, gip свой/чужой, pm, lead ОВ, staff, accountant, secretary
python modules/pm/tools/import_pm.py --registry data-dev\pm\MOST_Планирование_проектов.xlsx   # → data-dev\pm\pm-import.json, затем Сводка → «Импорт реестра»
```
Роли в браузере — cookie `devrole=gip|pm|lead|accountant|staff` (+ `devsection=ОВ` для руководителя раздела): у ГИП кнопки только в своих проектах, у руководителя раздела — галочки только своего раздела, staff — «нет доступа». Тестовая база `data-dev/pm/db.sqlite` — копия рабочей от 24.09 с импортированными 20 объектами (не коммитить).

Что смотреть глазами: Сводка (8 просрочено, 1 горит, 10 блокеров > 14 дн. — совпадает с дашбордом реестра), реестр РП → карточка «Бц Толе би» (этап 5, пункты этапов 1–4 отмечены), «Мои задачи» под `devrole=lead; devsection=ОВ`, Гант, вкладка «Бюджет» у объектов с бюджетом (Венеция 1 очередь, Эверест Парк, Толе би, Дзюдо, Меллиора 2, Алатауская, Хаят Арена 1, Теректи).

## Допущения и что осталось
- **Реестр с Google Drive**: сам xlsx скачать без искажений через коннектор не удалось (base64 бьётся), локальной копии на G: нет. Для теста собран `data-dev/pm/MOST_Планирование_проектов (реконструкция).xlsx` (скрипт `data-dev/pm/rebuild_registry.py`, данные 1:1 из содержимого файла). Перед боевым импортом скачать оригинал в `data-dev/pm/` и перегенерировать JSON — импортёр рассчитан на него.
- Даты реестра «оценочные» (так и написано в файле): после импорта почти все пункты просрочены (464). ГИПам нужно пройтись по карточкам: реальные даты, «Разложить сроки», лишние пункты — «не требуется». ГИПы в реестре не заполнены (`ГИП 1 (заменить)`) — назначает руководитель в «✎ Проект».
- Привязка к финансам — карта `FINANCE_MAP` в импортёре (Толе би → `Hayat Толе би`, Венеция 1 → `prj-011`, Меллиора 2 → `HM2`, Алмеу 1/2/3 → `Алмеу РП`, …; «Спорт центр» не привязан). Уточнить у директора; меняется в «✎ Проект» → «Финансовый проект».
- Регламент этап 6 (комплектация 1–2 нед. + ответы на замечания 2–3 нед.) в реестре один пункт — оставлен один пункт на 5 недель, чтобы было 79. Сроки концепции и АН — допущение.
- Файлы на сервере: `file://` из браузера обычно блокируется — есть «Скопировать путь». Создание папок — поток E / сисадмин.
- Дальше: события `pm.project.handover` (добавлено, в таблицу ARCHITECTURE не вписано — ждёт правки ядра), интеграция с hr (загрузка по пунктам и разделам), crm (`createProject` при подписании договора — сигнатура готова), экспорт реестра обратно в Excel, история изменений пункта.
