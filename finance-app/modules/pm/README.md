# Поток A — Управление проектами (`modules/pm`)

Основа — регламенты `\\MostServer\Материалы для проектирования\Регламенты\` («Регламент проектирования и разработки для РП.docx», «Дорожная карта проекта\Эскизный проект (ЭП)_06-10-2025.xmind») и реестр `MOST_Планирование_проектов.xlsx` (Google Drive; 20 объектов РП, блокеры, задачи из Trello, шаблон этапов из 79 пунктов). Бюджеты по разделам — `G:\Мой диск\Финансы\Бюджеты проектов\MOST_Проекты РП_Бюджет.xlsx`.

Уже есть: `domain.js` (шаблоны ЭП 8 этапов и РП 9 этапов, права, автоплан, сводка, бюджет), `server.js` (API: overview, my, projects CRUD, plan, handover, items, blockers). Экранов нет.

## Решения директора
- ЭП ведёт проектный менеджер (`pmId`), РП — ГИП (`gipId`). ЭП и РП — отдельные доски.
- ГИП и руководители разделов заходят только в этот модуль, финансов не видят.
- Бюджет и маржу видят руководители и ГИП/ПМ с флагом `seeBudget` у пользователя.
- В карточке ЭП — вкладка «Миро»: ссылка на доску (`miroUrl`), встраивание `https://miro.com/app/live-embed/<id>/`.

## Задачи
1. Экраны: Сводка (активные, просрочено, «горит» ≤14 дн., воронка по этапам ЭП и РП, загрузка ГИП/ПМ, Гант по месяцам), реестры ЭП и РП (фильтры: статус, мои), карточка проекта (шапка, этапы с чек-листом и критериями, отметка «сделано»/«не требуется», срок, исполнитель, заметка; блокеры; бюджет; Миро), «Мои задачи», «Блокеры».
2. Создание проекта, «Разложить сроки» (от старта или под дату по договору), «Передать в РП».
3. Шаблон РП сверить с таблицей (79 пунктов; сейчас в `domain.js` 68 — недостающие добавить с ролью и сроком из регламента).
4. Импорт: `tools/import_pm.py` (в папке модуля) — 20 объектов из реестра (этап → пункты прошлых этапов отмечены), блокеры, задачи Trello как дополнительные пункты, бюджеты разделов по проектам. Результат — JSON, загрузка кнопкой «Импорт» (только руководитель) через `POST /api/pm/import`.
5. Проверка прав каждой ролью: owner, gip (свой/чужой проект), pm, lead с разделом, staff (нет доступа), accountant.
6. Функция для коммерции: `createProject(ctx, fields, userId)` — уже есть, не ломать сигнатуру.
