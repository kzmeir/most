# Запросы потока F (ai) к ядру

1. **Сайт в ctx**: передавать модулям `ctx.site` ('erp' | 'fin' | 'all'). Сейчас модуль определяет сайт по порту запроса (`ERP_PORT`) — работает, но хрупко (прокси/туннель). От сайта зависит, какие места панели доступны: на ERP финансовые запросы закрыты.
2. **Модуль на сайте «Финансы»**: `modules/ai/server.js` объявляет `site: ['erp', 'fin']` — подключить `ui.js`/`domain.js` и `/api/ai/*` на обоих сайтах (координатор сообщил, что в erp/main это уже есть; в ветке erp/ai ядро пока старое, проверено в режиме DEV на одном порту).
3. Включить модуль `ai` в «Настройки → Модули» после входа Claude Code на сервере (или ключа API).
