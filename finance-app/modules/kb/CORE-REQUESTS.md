# Запросы к ядру от модуля kb (поток D)

1. **Хук после отрисовки меню.** Счётчики «Новости / Ознакомление / Обучение» модуль ставит в `#badge-<id>` сам: после своего раздела и по `hashchange` с задержкой 80 мс (меню перерисовывается в `route()`). Надёжнее — вызов `m.onNav?.(ui)` в конце `drawNav()` или общий `ui.setBadge(id, n)`, который переживает перерисовку. Тогда счётчик непрочитанных будет виден и из других модулей (например, на переключателе «Знания»).
2. **Лишние 403 у сотрудника.** `loadRefs()` запрашивает `/projects`, а `refreshBadge()` — `/docs` для всех ролей; у `staff` (и других без прав) в консоли браузера 403. Предлагаю вызывать их только при `canR('projects')` / `canR('docs')`.
3. **Новая коллекция модуля** `kbEnroll` (назначения обучения: новичок ↔ программа ↔ наставник). Регистрируется через `collections` в `modules/kb/server.js`, правка ядра не нужна; упомянуть в `docs/ARCHITECTURE.md`, если там будет список коллекций.
