# Поток D — Знания и обучение (`modules/kb`)

Модуль для всех сотрудников (роль `staff` и выше): новости бюро, база знаний, обучение новичков с нуля, тесты. Независим от других модулей.

Материал: `\\MostServer\Материалы для проектирования\Регламенты\` — «Список регламентов» (15 шт.: наименование файлов, ЗнП, график выдачи чертежей, чек-лист проверки РП, дорожная карта, оргструктура, матответственность, авторское право, неразглашение, регламент почты, программа стажировки, сдача СНиПов и книг, гайды по планировке и посадке с тестами), docx/pdf/xmind. Нормы — библиотека на диске `Y:\` (ссылки, не копии).

## Коллекции
`kbNews` (заголовок, текст, автор, дата, закреплено), `kbReads` (кто прочитал что), `kbArticles` (раздел, заголовок, текст, вложения/ссылки, теги), `kbCourses` (программа: недели → шаги → статьи/тесты, для кого), `kbTests` (вопросы: один/несколько вариантов, правильные ответы, проходной балл, попыток), `kbAttempts` (userId, testId, ответы, балл, дата).

## Задачи
1. Новости: лента, публикуют руководители и секретарь, отметка «прочитал», счётчик непрочитанных в меню.
2. База знаний: разделы (Регламенты, Гайды, Стандарты Revit ADSK, Нормы), поиск, статья с текстом и ссылками на файлы на сервере. Импорт текстов регламентов из docx (`tools/import_kb.py` в папке модуля, без npm).
3. Обучение: программа стажировки по неделям, наставник (userId), прогресс новичка в %, отметка шагов; руководитель раздела видит прогресс своих новичков.
4. Тесты: редактор вопросов (руководители), прохождение, балл, пересдача, история; событие `kb.test.passed`. Правильные ответы не отдаются в браузер до завершения попытки.
5. Документы для подписи новичком (NDA, авторское право, материальная ответственность): отметка «ознакомлен» с датой.

Права: читать — все вошедшие; писать новости/статьи — owner, partner, secretary; тесты и программы — owner, partner, lead. Модуль видят все роли (`canOpen: u => !!u`).
