**Черновик — на проверке у ГИП/ГАП.** Пилот: панель доступна только владельцу и партнёру.

# Что умеет
- По проекту: **план работ, ЗнП, ТЗ на раздел, протокол по заметкам, письмо заказчику**, «что горит», ответ на свободный вопрос.
- Без проекта: сводка «что горит», просрочки раздела, план по новому проекту.
- В «Финансах»: дебиторка, прогноз денег, субподрядчики по проекту — только чтение.

# Чего не делает
- **Ничего не меняет сам.** Любой ответ — черновик.
- «Применить» переносит план в проект только после вашего выбора, какие сроки и пункты взять.
- Зарплаты и личные данные сотрудников в ИИ **не передаются**; суммы договоров — только в финансовой панели.

# Как пользоваться
1. Модуль «ИИ» → выберите проект и команду (что сделать).
2. Ждите ответа: запросы идут по одному, от нескольких секунд до нескольких минут. Страницу можно закрыть — ответ сохранится в «Мои черновики».
3. Проверьте ответ. **Документ заказчику — только после вашей проверки.** «Скачать .docx» — Word в стиле MOST.

# Если не работает
Владелец видит журнал запросов и настройки. «Claude Code не выполнил вход» — на сервере нужно заново войти аккаунтом директора; «Проверить подключение» задаёт тестовый вопрос.
