# Как работать со стандартом
- У стандарта в шапке — дата принятия и изменений. Большинство — 2025–2026 годов, но **проверяйте дату** и берите последнюю редакцию.
- **Регион:** в шапке многих стоит «С2 North» (Астана, Караганда, Актау, Атырау, Актобе) или «С2 South» (Алматы, Шымкент, Ташкент). Для Алматы — таблицы South.
- Альбомы АТР парные по регионам (например, окна для Астаны и для Алматы) — это не дубли.
- Многие требования зависят от **класса**: Комфорт lite, Комфорт, Комфорт+, Бизнес, Бизнес+, Премиум.

Выжимки по разделам: «BI: архитектура жилья», «BI: двор и генплан», «BI: фасады по дизайн-коду», «BI: парковки».

# BIM-требования BI к моделям Revit
Документы — в «_Библиотеке BI»: «Технология информационного моделирования», файл общих параметров, чек-лист 2-го пакета, допустимые наименования типов, инструкция Family Manager; шаблоны АР, КЖ, ОВ, ВК. Копия библиотеки — январь 2025: **перед стартом проекта сверить версии шаблонов с BI** (актуальные — на портале BI Design).

**Модель**
- 1 файл = 1 блок + 1 раздел. Оси и уровни — в файле «БАЗА» (правят только архитекторы), в разделы — копированием с мониторингом.
- Общие координаты не сдвигать; DWG — только связью, не импортом; каждая связь — в своём рабочем наборе.
- Моделирование 1:1 без округлений; без дублей и наложений; типовые этажи моделируются.
- Сжатие файла раз в 1–3 недели, новый центральный файл — раз в 2–4 недели; передача — через «Передать модель» с очисткой.

**Параметры и имена**
- Общие параметры с префиксом **BI_** (BI_этаж, BI_секция, BI_квартира, BI_площадь_квартиры_общая/жилая, BI_тип_помещения, BI_марка_изделия, BI_штамп_…).
- Семейства: «(Категория)Описание_через_подчёркивание», например «(Двери)Металлическая_Однопольная_Техническая»; только из Family Manager.
- Отклонения от стандарта — суффиксом: _бизнес, _премиум, _согласовано, _СТУ, _норматив, _расчет.
- Виды: «01 Этаж_+0,000_(Отделочный)»; спецификации: «01_АР_(Группа)_Название»; материалы: «BI_Класс_Название», RAL фасадных — в «Комментариях».
- ТЭП и квартирография — плагином BI «Квартирограф».

**Обмен и проверка**
- Обмен через BIM 360 / ACC по регламенту загрузки.
- Проверка: визуальная → коллизии (Navisworks + BIM Inspector) → атрибуты (BIM Inspector for Revit).
- Чек-лист 2-го пакета: общие координаты, наименования, квартирография (100 %), параметры помещений и машино-мест.
- Модель обязательно актуализируется при изменении отметок, осей, трасс сетей и дорогих элементов (окна, фасадные плиты, кладка, армирование).

Наши собственные модели — на стандарте ADSK (см. «Стандарт ADSK: с чего начать»). Для проектов BI — шаблоны и параметры BI.
