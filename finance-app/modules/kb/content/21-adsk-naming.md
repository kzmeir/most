# Имена типов
**Код автора_Функция_Структура_Толщина** → ADSK_Наружная_Газобетон400 ут150 шт20-вентфасад60_630.
Структура: основной слой с толщиной → слои наружу → внутренняя отделка → тире → наружная отделка. Свои типы — со своим кодом автора, не ADSK_.

# Имена видов
**Код_Раздел_Семейство вида_Этаж_Описание** → О_АР_ПЭ_02 Этаж_Кладочный.
- **В** — вспомогательный вид (для работы), **О** — оформленный (идёт на лист).
- ПЭ — план этажа, ПП — план потолка, Ф — фасад.
- Номер этажа ставим **в начало** поля — так виды сортируются правильно.

# Оформление
- Шрифт **GOST Common** (для КЖ/КМ — GOST Common SpecSymbol); после установки перезапустить Revit.
- Текст — ADSK_Основной текст_2.5; размеры — ADSK_Основной_2.5 мм (есть с округлением 5 и 10 мм и для ГП в метрах).
- Веса линий: разрез — №4, проекции — №2, толстые (армирование, схемы) — 5…9; №1 — только для штриховок.
- Номер разреза/фрагмента появляется только **после размещения вида на листе** и должен быть уникален на листе.
- Экспорт DWG: заказчику — набор «ADSK_MIN слоёв», подрядчикам и в архив — «ADSK_Все категории».

# Штамп
- Формат листа — параметры «Формат А» и «Кратность»; ошибка → на листе печатается «ФОРМАТ НЕ ПО ГОСТ».
- Номер и наименование проекта, стадия, заказчик — в «Сведениях о проекте».
- Чтобы значение повторялось на всех листах, параметр переводят из категории «Листы» в «Сведения о проекте».

# Марки
Имя типа марки говорит, какие параметры она показывает. Нужна другая информация — **выберите другой типоразмер марки**, семейство не правьте.
