# Поток B — Персонал: команды, табель, стоимость часа, загрузка (`modules/hr`)

Исходные данные: сотрудники `db.employees` (43, должности и даты приёма в базе почти пустые), ЗП `db.payroll`, ставки налогов `settings.tax` (`D.payrollTaxes`), праздники РК `D.isHoliday`, проекты и пункты модуля pm (`db.pmProjects`, `db.pmItems`), отпуска `db.vacations`. Состав команд — лист «ФОТ» в `G:\Мой диск\Финансы\Бюджеты проектов\MOST_Проекты РП_Бюджет.xlsx` (блок «Состав команд»: АР 16, ГИП 2, ОВ 3, ВК 2, ГП 3, АДМ 4).

## Коллекции
- `hrTeams` — `{ id, name, section (АР…Офис), leadUserId, members: [employeeId], note }`.
- `hrTimesheets` — `{ id, employeeId, week: '2026-W40', status: draft|submitted|accepted|rejected, lines: [{ kind: project|office|absence, pid (pmProjects.id), section, hours: [пн…вс], note }], total, submittedAt/By, acceptedAt/By, rejectNote, rejectedAt/By }`; одна запись на сотрудника и неделю.
- `hrPeople` — карточка сотрудника в модуле, ключ = `employees.id`: `{ position, hoursPerWeek (норма, по умолчанию 40), userId (запасная связь с пользователем), note, bonusMonthly (премия в месяц на руки), bonus13 (13-я ЗП), rateOverride (ставка часа вручную) }`. Сами сотрудники (ФИО, оклад, дата приёма, статус) остаются в `db.employees` и меняются в финансах.

## Сделано (24.09.2026, ветка erp/hr)

**domain.js** (`window.MostHR`, UMD): роли (`isMoney` = owner/partner/accountant, `isManager` = owner/partner, `canViewAll` + secretary, `canPlan` + pm/gip/lead), недели ISO (`isoWeek`, `weekStart`, `weekDates`, `addWeeks`, `weekMonth` — месяц недели по четвергу, `lastWeeks`, `weekTitle`), норма часов месяца и недели без праздников РК (`normHours`, `weekNorm`), **ставка часа** `rateCalc` = (затраты работодателя по `D.payrollTaxes` + премия с налогами + 1/12 оклада при 13-й ЗП) / норма часов месяца, ручная ставка перекрывает; итоги и валидация табеля (`tsTotals`, `cleanLines` — шаг 0,25 ч, `validateLines` — ≤ 24 ч в ячейке и в день, проект обязателен); **план загрузки** `planLoad` по срокам пунктов pm.

**server.js** (`/api/hr/*`, все права на сервере; на сайте ERP финансовых API нет — модуль сам читает `db.employees`, `db.payroll` не нужен, налоги считает из настроек):
`GET me`, `GET badges` (`hrtime` — мои несданные недели за 4 недели, с пятницы + текущая; `hrreview` — сданные табели, ждущие моего решения), `GET|POST teams`, `GET|PUT|DELETE teams/:id`, `POST teams/:id/members`, `DELETE teams/:id/members/:employeeId`, `GET employees[?all=1]`, `GET|PUT employees/:id`, `GET timesheet?employeeId&week`, `PUT timesheet` (черновик), `POST timesheet/submit|accept|reject|reopen`, `GET timesheets?week&n` (статусы людей за n недель), `GET load?to&n` (факт: люди × недели, проекты × недели, разделы), `GET plan?n` (план разделов × недели против ёмкости команд), `GET rates?ym` (деньги), `GET cost?from&to&draft`, `GET cost/:pid` (деньги), `POST import` (команды из JSON).
Функции для других модулей: **`ctx.modules.hr.laborCost(ctx, pmProjectId, { from, to, includeDraft })`** → `{ hours, cost, bySection, byEmployee, byMonth, byStatus, weeks }` и `laborHours(...)` — то же без денег; `ctx.modules.hr.domain` — MostHR. Деньги из `laborCost` показывать только при `ctx.modules.hr.domain.isMoney(user)`.

Права: сотрудник — свой табель (связь `users.employeeId`, запасная `hrPeople.userId`, в разработке — cookie `devemployee`); руководитель раздела — табели команд, где он `leadUserId` или раздел команды = его `section` (принимает, возвращает, заполняет за сотрудника, правит состав; свой табель принять не может); owner/partner — всё, команды, импорт; accountant — всё видит + деньги + премии/ставки в карточке, табели не принимает; secretary — всё видит без денег; gip/pm — свой табель, загрузка и план (часы). Оклады, ставка часа, себестоимость — только owner/partner/accountant (для остальных полей просто нет в ответе; `rates`/`cost` — 403).

**ui.js** — экраны: **Табель** (неделя стрелками, строки проект/офис/отсутствие + раздел + 7 дней, итоги против нормы, «+ Строка», «Как на прошлой неделе», Сохранить / Сдать / Принять / Вернуть / В работу, переключатель сотрудника для руководителей, подсказка про привязку аккаунта), **Табели команды** (люди × 4 недели со статусами и часами, принять/вернуть, «Принять все сданные»), **Загрузка** (вкладки: факт по неделям с цветом относительно нормы и статусом табеля, по проектам, по разделам; план на 9 недель: разделы × недели «план / ёмкость», колонка «Долг» — часы просроченных пунктов, раскрытие пунктов, назначенные исполнители), **Команды** (карточки команд с составом, руководителем, «+ Команда», состав галочками, «+ Сотрудник», «→ в команду» для людей без команды, «⇪ Импорт из ФОТ»), **карточка сотрудника** `#/hremp?id=` (пользователь, команды, норма, дата приёма; для MONEY — разбор ставки часа; 8 недель часов и проекты; ✎ карточка), **Ставки и себестоимость** (MONEY: ставка часа по всем за месяц с итогами; себестоимость проектов за 12/26/52 недель или всё время, с черновиками или без, раскрытие проекта: по людям, разделам, месяцам и сравнение с планом «Внутренние» из бюджета pm). Инструкция модуля (`help`, 6 разделов), счётчики через `ui.setBadge` + `onNav`.

**tools/import_fot.js** — лист «ФОТ» → `data-dev/hr/hr-import.json`: имена листа («Таня», «Стас», «Худайберганов») сопоставляются с `db.employees` по словам ФИО (опечатки до 1 буквы, уменьшительные) и окладу; отчёт: не найдены / неоднозначно / уволены / есть в базе, но не в листе. На бэкапе 24.09: 30 человек в 6 командах, 0 не найдено, 4 уволенных пропущено, 6 новых сотрудников (стажёры 2026 и Иманкулов И.) — без команды, расставить руками.

**tests/api_test.sh** — 91 проверка по ролям (owner, partner, accountant, secretary, gip, lead АР/ОВ, staff с привязкой и без): команды, карточка и деньги, табель (валидация, сдача, возврат с причиной, принятие, повторное открытие, чужие табели), списки и счётчики, загрузка и план, ставки и себестоимость (ручная ставка, черновики), импорт, два сайта (`DEV_SPLIT=1`: на ERP-порту `/api/employees` — 404, `/api/hr/*` — работает).

## Допущения и что осталось
- **Связь аккаунт ↔ сотрудник** на рабочей базе пока не заполнена (2 пользователя, у обоих `employeeId` пуст): владелец задаёт в «Настройки → Пользователи» или в карточке сотрудника здесь. Без связи сотрудник видит подсказку вместо табеля.
- **Должности и даты приёма** в `db.employees` пустые — должности подтянуты из листа «ФОТ» в `hrPeople.position`; даты приёма правятся в финансах (CORE не нужен). Оклады листа и базы расходятся у 9 человек (лист старее) — считаем по базе.
- **Ставка часа**: налоги по `settings.tax` (ставки 2026 сверить с бухгалтером), премия — средняя в месяц из карточки, 13-я ЗП — флаг. Перенос праздника с выходного на понедельник `D.isHoliday` не учитывает (ядро). Себестоимость считается по ставке месяца недели (неделя целиком относится к месяцу четверга).
- **План загрузки**: допущение «пункт = один специалист на полную ставку в течение нормативных недель»; просроченные пункты — в колонке «Долг». Пункты без раздела (ожидания заказчика) не считаются. Разделы КЖ, ЭЛ, СС, ГСВ, ТХ, Смета — без команд (субподряд/нет людей) → ёмкость 0.
- **Напоминание в пятницу** — по решению директора уведомлений нет: счётчик у «Табеля» с пятницы включает текущую неделю (`ctx.modules.sys.notify` не используется).
- Дальше: интеграция в карточку проекта pm (вкладка «Часы»: `laborHours` всем, `laborCost` — при `isMoney`), вкладка загрузки «по людям» в плане (сейчас — по разделам и назначенным исполнителям), мобильная раскладка табеля (пока горизонтальная прокрутка таблицы), экспорт табелей/себестоимости в CSV для 1С и бюджетов, учёт отпусков из `db.vacations` в самом табеле (сейчас — только в ёмкости плана), премии по факту из ведомости ЗП (`payroll.lines`).
