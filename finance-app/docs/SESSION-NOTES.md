# Хроника разработки MOST Финансы (сентябрь 2026)

Сжатая запись переписки с владельцем: что просили, что решили, что сделано. Чат вёлся в Claude Code (сессия https://claude.ai/code/session_01YTim1SUqmHrx7aQt55tb75), продолжение — локально в этой папке, контекст в `CLAUDE.md`.

## Исходная задача

Одна система для всех финансов компании вместо разрозненных таблиц и выписок. Пользователи: владелец, партнёр, бухгалтер, ПМ (только просмотр). Главная боль — долгое ожидание бухгалтера по актам и счетам → очередь запросов со статусами и счётчиком дней. Требование: данные компании не должны жить только в облаке → офисная версия на MostServer с локальной базой; облачная (артефакт claude.ai) принята как рабочая с обязательными бэкапами. 1С: только обмен CSV.

## Решения по порядку

1. **Стек**: Node.js без npm-зависимостей, JSON-база, авторизация scrypt + cookie, роли на сервере. Запуск двойным кликом `start.bat`. Zip передаётся владельцу для копирования в `\\MostServer\Documents\MOST-Финансы`.
2. **Веб-версия** на артефакте claude.ai с общей базой (capability db), входом по аккаунту claude.ai (user), скачиванием (downloads), позже файлами (assets). Правила базы: корень читают все вошедшие, пишут редакторы; opsm/payroll/employees/vacations/obligations/cash/proposals/accounts/categories/meta — только редакторы.
3. **Модель по таблице «Бюджет МОСТ»**: операции с проектом и категорией, реестры договоров с заказчиками и подрядчиками, АВР, КП, справочники счетов и категорий. Импортёр `tools/import_budget.py`, 9 810 операций, 217 договоров, 157 подрядных, 47 АВР, 153 проекта (проекты из реестра договоров добавлены после замечания «проекты не полные»).
4. **Операции**: фильтры (период, компания, счёт, категория, проект, вид, источник, сумма, текст), сортировка, все столбцы таблицы включая № операции и комментарий, инлайн-правка проекта/категории, автоподсказки по истории (пометка «авто», подтверждение галочкой).
5. **Выписки**: Kaspi Business PDF (разбор по координатам, повёрнутые страницы, сверка с исходящим остатком), Excel/CSV любого банка; дедупликация по счёту/дате/сумме/№ документа; опорный остаток счёта записывается при загрузке.
6. **ЗП/ФОТ**: сотрудники (43, из ведомости), месяцы с раскрывающимися строками, отпуска: 24 дня в год, праздники РК, календарь.
7. **Стиль**: брендбук MOST (оранжевый FF4D23, чёрный, серый 686A6D, Neue Haas Grotesk), логотип извлечён из бланка КП и переведён в вектор (файл about_logo.png с Drive оказался иконкой WhatsApp).
8. **Счета к оплате**: загрузка из Excel/CSV-реестра и PDF-счетов (номер, дата, поставщик, сумма читаются из текста), файл счёта прикрепляется и открывается по клику; вложения затем добавлены договорам, подрядчикам, КП и актам.
9. **Аудит пробелов** («что не учли») → сделано: восстановление из JSON-копии, напоминание о бэкапе в веб-версии, остатки по счетам из операций (опорный остаток + операции после него), платёжный календарь с согласованием владельцем/партнёром, счета из обязательных платежей за месяц, отчёты по месяцам/компаниям/категориям/проектам.
10. **Задел на ERP** → сделано: справочник контрагентов с псевдонимами и объединением, связки проект → договор → акт → операция, авторазнесение приходов по договорам клиентов (по номеру договора/акта в назначении, названию проекта, единственному открытому договору), карточка проекта с план/фактом и стадиями, генератор КП по шаблонам Концепт/ЭП/РП/АН (тексты концепции и ЭП — из реальных КП бюро; РП и АН составлены как заготовки, ставки-заглушки: РП 3500 ₸/м², АН 1 000 000 ₸/мес).
11. **Секретарь**: сначала ограниченная роль, по просьбе владельца — полный доступ, кроме дашборда; согласовывать оплату не может. Инструкция пользователя: раздел «Инструкция» в системе и отдельная страница https://claude.ai/artifact/3zaDTSRyniGQfgQvuov5xD.
12. **Доступ по логину и паролю**: в claude.ai невозможен (вход только по аккаунту организации, база закрыта для анонимов, страница с файлами не публикуется). Выбран путь «MostServer + Cloudflare Tunnel»: `start-internet.bat`, `install-autostart.bat`, `tools/add_user.js`, адрес виден в Настройках. Данные из веб-версии переносятся через «Скачать всю базу» → «Восстановить из файла».

## Ограничения и советы владельцу

- Не разнесено около 1000 операций (без категории/проекта или «авто») — подтверждать в фильтре «не разнесено / авто».
- Выписка MOST Project ни разу не загружалась; опорные остатки счетов не заданы → расчёт остатков покажет прочерк до первой выписки.
- Даты приёма сотрудников пустые → отпускные дни считаются с 01.01.2026.
- Веб-версия бэкапится только вручную; после переезда на MostServer вести учёт в одном месте.
- Право «Может редактировать» в веб-версии технически открывает всю базу; внешним людям его не выдавать.
