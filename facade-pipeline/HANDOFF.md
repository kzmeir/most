## 1. Цель

Поставить **на поток** генерацию фасадов в стиле современной неоклассики для проекта
BI-EXPO. Метод — **harvest & loop**: собрать референсы → выжать «стиль-ДНК» →
генерить циклами с отбором → лучшее вернуть в референсы (петля сходится к canon).

Исходные референсы лежали у автора: `Y:\Concept Projects EP\_Рассмотрение\2026\BI-EXPO\05-Reference`
(этот путь доступен только на локальной машине автора, не в облачной сессии).

**Открытый вопрос (нужно решить в локальной сессии):** тип объекта BI-EXPO —
жилой дом / офис / МФК / выставочный павильон? От этого зависит выбор пресета.
По умолчанию в примерах использован MFC (mixed-use).

## 2. Анализ стиля (по 15 референсам)

Стилистика: **современная неоклассика / «новая классика»** — европейская городская
архитектура премиум-класса (Лондон, Гамбург, Париж, Москва). Спокойная, вневременная.

Повторяющиеся признаки:
- **Материал:** светлый камень — известняк / травертин / Portland stone; тёплый
  бежево-кремовый и белый; матовая фактура.
- **Композиция:** трёхчастная — выраженный стилобат/база (аркада или витрины) →
  основное «тело» → отступленный аттик/пентхаус.
- **Ритм:** вертикальные каннелированные пилястры и простенки, глубокие оконные откосы.
- **Аркады:** полуциркульные арки в уровне 1 этажа (Гамбург, Лондон, Москва).
- **Окна:** крупные, «французские», тонкие тёмные бронзовые/антрацитовые профили,
  стеклянные ограждения балконов.
- **Приём «старое + новое»:** сохранённый исторический ордерный фасад + современная
  надстройка (бронзовое остекление, стеклянная «корона», чёрный объём).
- **Детали:** сдержанный ордер, карнизы, руст, минимум декора.
- **Подача:** рассвет/закат, чистое небо, тёплый свет в окнах, архитектурная
  фотография, люди и авто для масштаба.

## 3. Генератор: Nano Banana (Gemini 2.5 Flash Image)

Выбран **Nano Banana = `gemini-2.5-flash-image`**. Особенности (важно для промптинга):
1. Промпт — **связное описание предложениями**, не теги через запятую.
2. «Замок стиля» = **вложенные картинки-референсы** (2–3 работают уверенно), а не
   коды типа `--sref`.
3. Итеративное редактирование в одном диалоге держит консистентность — правь
   **по одному параметру** за прогон.
4. «Старое + новое» — killer-feature: можно приложить реальное фото исторического
   фасада участка и сказать «сохрани его, надстрой современный объём».
5. Соотношение сторон задаётся **словами** в промпте (`Vertical 4:5 framing`).

## 5. Петля harvest & loop

```
HARVEST → DISTILL → [приложить 2–3 style-core + промпт] → LOOP → CURATE → назад в style-core
   ▲                                                                          │
   └───────────────────────────── feedback ───────────────────────────────────┘
```

Правила: менять один параметр за правку; держать `01_style-core` чистым (≤15 картинок);
после 3–4 итераций фиксировать промпт как «canon vN» в `log.md`. Подробно — в
`02_prompts/loop-checklist.md`.

## 6. Приложение Facade Studio (`app/index.html`)

Самодостаточный одностраничный веб-апп (без сборки/сервера). Напрямую зовёт Gemini API,
реализует всю петлю: 4 пресета, до 3 референсов, 1–4 вариации, лента, кнопка
**«⟳ в референсы»** (замыкает петлю), скачивание. Ключ хранится только в localStorage,
в репозиторий не попадает.

Запуск: получить ключ на aistudio.google.com/apikey → открыть `index.html` → вставить
ключ → выбрать пресет → приложить референсы → «Сгенерировать».
Опубликовать на сайте студии: `cp facade-pipeline/app/index.html most-site/facade-studio.html`.

## 7. Статус доступа к API (проверено в облачной сессии)

Проверяли ключ, выданный автором. Результаты:

| Проверка | Результат |
|---|---|
| Связь с `generativelanguage.googleapis.com` из сессии | ✅ есть |
| Ключ валиден (текстовая модель `gemini-2.5-flash`) | ✅ HTTP 200 |
| `gemini-2.5-flash-image` (Nano Banana) | ⛔ `429 — free_tier limit: 0` |
| `gemini-2.5-flash-image-preview` | ⛔ `404` (имени нет) |

**Вывод:** генерация изображений Nano Banana **не работает на бесплатном тарифе**
(лимит = 0). Нужен включённый **биллинг** на проекте ключа. Текст — бесплатен, картинки — нет.

**Важно про Google Flow:** бесплатные генерации во Flow — это потребительская квота
подписки Google AI Pro/Ultra, живёт **только внутри веб-приложения Flow** под
Google-логином. Через API-ключ она **недоступна** (у Flow нет публичного API). Две
квоты не связаны.

## 8. Почему нельзя «сделать через браузер»

- Облачная сессия изолирована — **нет доступа к браузеру автора** (нет моста к его вкладке).
- Свой headless-Chromium в контейнере **не залогинен в Google-аккаунт автора**, значит
  подписки Flow у него нет.
- Автоматический вход в Google блокируется (2FA + антибот), и **вводить Google-логин
  автора через чужую среду нельзя по безопасности**. Этот путь закрыт.

## 9. Два рабочих пути (выбрать в локальной сессии)

| Путь | Кто жмёт generate | Стоимость | Кто ведёт петлю |
|---|---|---|---|
| **A. Flow (бесплатно)** | автор в интерфейсе Flow | 0 (подписка) | Claude — выдаёт промпты, разбирает результат, ведёт log |
| **B. API + биллинг** | Claude автоматически | ~$0.039/картинка | Claude целиком |

**Локальная сессия снимает часть барьеров пути A/B:** локально Claude Code может
управлять твоим браузером напрямую (если настроить), а ключ/логин остаются на твоей
машине. Но самое простое:
- **Путь B локально:** включить биллинг на проекте ключа → Claude сам гоняет батчи
  скриптом (готовый образец скрипта — см. §10) и складывает PNG в `03_output/`.
- **Путь A:** Claude выдаёт промпт → ты генеришь во Flow бесплатно → возвращаешь картинку.

## 10. Готовый скрипт-генератор (для пути B)

В облачной сессии использовался Python-скрипт, который шлёт запрос к
`gemini-2.5-flash-image` и сохраняет PNG. Логика (воссоздать локально в
`facade-pipeline/app/gen.py`):

- читать ключ из переменной окружения или локального файла (НЕ коммитить ключ);
- собрать `contents:[{role:user, parts:[{text:prompt}, {inlineData:{mimeType,data(base64)}}...]}]`;
- POST на `.../v1beta/models/gemini-2.5-flash-image:generateContent?key=KEY`;
- из `candidates[0].content.parts[]` взять part с `inlineData.data`, декодировать base64 → PNG;
- параметры: `--prompt-file`, `--out DIR`, `--n`, `--ref img...`, `--model`.

(Полный текст скрипта был во временной папке облачной сессии и не коммитился вместе
с ключом; воссоздать по описанию выше — он короткий.)
