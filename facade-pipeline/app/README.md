# Facade Studio — приложение для harvest &amp; loop

Одностраничное веб-приложение (один файл `index.html`, без сборки и сервера).
Напрямую обращается к **Gemini API** (`gemini-2.5-flash-image`, он же **Nano Banana**)
и реализует всю петлю генерации фасадов: пресеты → референсы стиля → генерация →
возврат лучшего в референсы.

## Как запустить

1. **Получить ключ:** [aistudio.google.com/apikey](https://aistudio.google.com/apikey) → *Create API key*.
2. **Открыть приложение:** дважды кликнуть `index.html` (откроется в браузере).
   *Chrome рекомендуется.*
3. Вставить ключ в поле **«1 · Ключ и модель»**. Ключ сохраняется только в этом
   браузере (localStorage) и **никогда не уходит в репозиторий**.
4. Выбрать пресет, приложить 2–3 референса, нажать **«Сгенерировать»**.

## Петля прямо в интерфейсе

- **⟳ в референсы** на карточке результата — кладёт удачную генерацию в набор
  референсов. Следующий прогон пойдёт уже от твоего canon → стиль сходится.
- Правь промпт **по одному параметру** за прогон.
- **↓ скачать** / **Скачать всё** — сохранить кадры (потом в `../04_selects/`).

## Пресеты

Совпадают с `../02_prompts/master-prompt.md`:
1. Новая классика · жилой камень
2. Офис · аркада (Portland stone)
3. Старое + новое (facade retention) — приложи реальное фото исторического фасада
4. Белая крашеная классика (флагман)

## Замечания

- **Модель:** по умолчанию `gemini-2.5-flash-image`. Если у ключа нет доступа —
  впиши `gemini-2.5-flash-image-preview`.
- **Соотношение сторон** задаётся словами в промпте (`Vertical 4:5 framing` и т.п.).
- **Тарификация:** каждый вызов оплачивается по прайсу Gemini API на твоём ключе.
  «Сколько вариаций» = столько отдельных запросов.
- **Безопасность:** файл можно открывать локально. Если положишь его на публичный
  сайт — ключ всё равно вводит каждый пользователь у себя, в коде ключа нет.

## Опубликовать на сайте (необязательно)

Файл лежит вне `most-site/`, поэтому на прод-сайт **не** попадает автоматически.
Чтобы захостить на домене студии — скопируй его в сайт:

```
cp facade-pipeline/app/index.html most-site/facade-studio.html
```

После деплоя Render будет доступен по адресу `…/facade-studio.html`.
