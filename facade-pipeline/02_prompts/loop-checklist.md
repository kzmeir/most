# Loop Checklist — «harvest & loop» для генерации фасадов (Nano Banana)

Замкнутая петля: **собрать → выжать стиль → генерить циклами → отобрать →
лучшее вернуть в эталоны.** Стиль сходится к твоему канону, а не «плавает».

```
HARVEST → DISTILL → [приложить 2–3 style-core + промпт] → LOOP → CURATE → назад в style-core
   ▲                                                                          │
   └───────────────────────────── feedback ───────────────────────────────────┘
```

## Папки

```
facade-pipeline/
  00_harvest/     ← все входящие референсы, без разбора
  01_style-core/  ← 8–15 лучших, задают «каноничный» стиль (эталоны для NB)
  02_prompts/     ← master-prompt.md, loop-checklist.md, log.md
  03_output/      ← генерации по прогонам: 2026-08-05_run01/ ...
  04_selects/     ← отобранное лучшее → возвращается в 01_style-core
```

## Чек-лист одного прогона

- [ ] **1. Harvest.** Новые референсы кинуть в `00_harvest/`. Только 100%-«в стиле» → перенести в `01_style-core/`.
- [ ] **2. Distill.** Выбрать пресет в `master-prompt.md`, подставить `[BUILDING_TYPE]`, `[BASE]`, `[VIEW]`, `[FRAMING]`.
- [ ] **3. Seed.** В Nano Banana: промпт + **приложить 2–3 картинки** из `01_style-core` под этот подстиль → базовый кадр.
- [ ] **4. Loop.** Править **по одному параметру** в том же чате (список правок — внизу master-prompt.md). Стиль держится сам.
- [ ] **5. Curate.** Удачные кадры → `03_output/ГГГГ-ММ-ДД_runNN/`, лучшие 5–10% → `04_selects/`.
- [ ] **6. Feedback.** Лучший кадр из `04_selects/` перенести/скопировать в `01_style-core/` — в следующей сессии прикладываешь уже СВОЙ canon.
- [ ] **7. Log.** Записать строку в `log.md`.

## Правила, чтобы поток был управляемым

1. **Меняй один параметр за правку** — иначе непонятно, что дало эффект.
2. **`01_style-core` держи чистым** — максимум 10–15 картинок, только эталоны. Разрастётся — стиль «размоется».
3. **После 3–4 итераций** петля выдаёт результат предсказуемо: фиксируй промпт-версию в `log.md` как «canon vN».
4. **Consistency-трюк NB:** чтобы серия зданий была в одном стиле — прикладывай один и тот же набор из `01_style-core` во всех прогонах.

## Опция: Google Flow (видео)

Если нужен не только статичный фасад:
1. Прогони фасады по петле выше (Nano Banana).
2. Лучшие кадры из `04_selects/` → в Flow как **Ingredients / Frames**.
3. Оживи: пролёт камеры, смена света день→вечер, движение людей/машин.
> Для только статичных фасадов Flow не нужен — хватит Gemini-приложения / AI Studio.
