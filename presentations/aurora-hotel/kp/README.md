# Коммерческое предложение — концепция и эскизный проект

Гостиничный комплекс, г. Алматы, ул. Бухтарминская. Только стадии
«концепция» и «эскизный проект»; рабочая документация в предложение не входит.

| Файл | Назначение |
|---|---|
| `MOST_KP_Bukhtarminskaya_EP.docx` | Редактируемая версия для правки и подписи |
| `MOST_KP_Bukhtarminskaya_EP.pdf` | Для отправки заказчику |
| `kp.js` | Генератор (docx-js) |

Пересборка: `npm install docx && node kp.js`

## Стоимость

Ставка 2 000 ₸/м² от расчётной площади 27 521,32 м², внутреннее деление 30 / 70.

| Стадия | ₸/м² | Сумма |
|---|---|---|
| Концепция (30 %) | 600 | 16 512 792 ₸ |
| Эскизный проект (70 %) | 1 400 | 38 529 848 ₸ |
| Итого | 2 000 | 55 042 640 ₸ |

## Что нужно проверить перед отправкой

- **Ставка за дополнительные итерации** (раздел 7) — поле пустое.
- **НДС** — указано «без учёта НДС», сверить с налоговым статусом бюро.
- **Сроки** 3 + 4 недели — предложение, не согласованная величина.
- **Порядок оплаты** 50/50 по каждой стадии — предложение.
- **Реквизиты исполнителя** — в блоке подписей только наименование.
- **База площади.** 27 521,32 м² включает расчётные величины: коридоры по
  коэффициенту 0,70 и подземный этаж по пятну застройки. В разделе 1 есть
  оговорка о пересчёте по фактической площади с сохранением ставки за м² —
  не удалять, это защищает обе стороны.
