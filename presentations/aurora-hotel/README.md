# AURORA HOTEL — презентация для акимата г. Алматы

Гостиничный комплекс категории 4 звезды, г. Алматы, ул. Бухтарминская.
Стадия — концепция. 17 слайдов, 16:9.

## Файлы

| Файл | Назначение |
|---|---|
| `AURORA_HOTEL_akimat.pptx` | Презентация для показа и правки |
| `AURORA_HOTEL_akimat.pdf` | То же для рассылки и печати |
| `build.js` | Генератор деки (pptxgenjs) |
| `assets/` | Изображения: визуализации, фрагменты генплана, логотип |

## Пересборка

```bash
npm install pptxgenjs
node build.js
```

## Оформление

Фирменный стиль MOST: белый лист, оранжевый `#FF4D23`, Helvetica/Arial,
мелкие прописные подписи по углам, полноэкранные визуализации,
логотип M справа внизу, капсулы-теги стадий на титуле и контактах.
Логотип собран из `most-site/orange.svg`.

## Источники данных

Все площади и отступы — из проекта генерального плана (ТЭП от 27.08.2026):
участок 1,4 га, застройка 4 941,11 м², 1-й этаж 4 446,9 м²,
номерной фонд 12 693,32 м², общая площадь 17 140,22 м², 5 этажей,
отступы 6,00 / 3,00 / 17,49 / 6,00 м.

Коэффициенты посчитаны из них арифметически:
застройка 35,3 %, КИТ 1,22, вне пятна застройки 9 058,89 м² (64,7 %),
доля номерного фонда 74,1 %.

## Что заполнить до показа

Оценочные и незаполненные значения помечены в деке; см. также заметки к слайдам.

- Слайд 13 — количество машино-мест (на генплане парковка не размечена).
- Слайд 15 — объём инвестиций, налоговые поступления, рабочие места на
  период строительства, гостиничный оператор, срок ввода.
- Слайд 16 — календарные сроки этапов.
- Слайд 11 и 15 — ёмкость 260–300 номеров и 160–210 рабочих мест даны
  **оценочно**, расчёт приведён в заметках к слайдам.
- Слайд 2 — район города и кадастровый номер участка.
