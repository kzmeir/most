# Гостиничный комплекс на ул. Бухтарминской — презентация для акимата г. Алматы

Гостиничный комплекс категории 4 звезды. Стадия — concept. 17 слайдов, 16:9.

## Файлы

| Файл | Назначение |
|---|---|
| `MOST_Bukhtarminskaya_akimat.pptx` | Презентация для показа и правки |
| `MOST_Bukhtarminskaya_akimat.pdf` | То же для рассылки и печати |
| `build.js` | Генератор деки (pptxgenjs) |
| `assets/` | Визуализации, визуализированный генплан и его фрагменты, логотип, QR |

## Пересборка

```bash
npm install pptxgenjs
node build.js
```

## Оформление

Фирменный стиль MOST по образцу презентации BI/DCT Dream City: белый лист,
оранжевый `#FF4D23`, Helvetica/Arial, мелкие прописные подписи по углам,
полноэкранные визуализации, логотип M справа внизу, капсулы стадий
(`concept / masterplan / project / detail plan`) на титуле и контактном листе.

Архитектурный блок открывает схема генезиса формы (слайд 9): силуэт
Заилийского Алатау в три шага сглаживается до лент перекрытий.

Логотип собран из `most-site/orange.svg`. QR восстановлен по модульной сетке
из контактного листа референса, ведёт на `https://most-a.com/`; в центр
вписана фирменная M, читаемость проверена декодером.

## Источники данных

Все площади и отступы — из проекта генерального плана (ТЭП от 27.08.2026):
участок 1,4 га, застройка 4 941,11 м², 1-й этаж 4 446,9 м²,
номерной фонд 12 693,32 м², общая площадь 17 140,22 м², 5 этажей,
отступы 6,00 / 3,00 / 17,49 / 6,00 м.

Коэффициенты посчитаны из них арифметически: застройка 35,3 %, КИТ 1,22,
вне пятна застройки 9 058,89 м² (64,7 %), доля номерного фонда 74,1 %.

## Что заполнить до показа

Оценочные и незаполненные значения помечены в деке; см. заметки к слайдам.

- Слайд 14 — вместимость подземного паркинга. На визуализированном генплане
  читаются рампа под корпусом и ряд наземных гостевых мест, но число мест
  не подписано.
- Слайд 16 — объём инвестиций, налоговые поступления, рабочие места на
  период строительства, гостиничный оператор, срок ввода.
- Слайды 12 и 16 — ёмкость 260–300 номеров и 160–210 рабочих мест даны
  **оценочно**, расчёт приведён в заметках к слайдам.
- Слайд 2 — район города и кадастровый номер участка.

Три запроса к акимату (одобрить концепцию, выдать АПЗ, определить
технические условия) вынесены в заметки к контактному листу — озвучиваются
устно, отдельного слайда под них нет.
